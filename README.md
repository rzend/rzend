## 📂 Projetos em Destaque

### 🌟 [Personal Finance Web](https://github.com/rzend/personal-finance-web)
Aplicação web para **gestão financeira inteligente**, construída em **Angular + TypeScript**.  
Principais destaques:
- Autenticação JWT e gestão de perfil.  
- Dashboard interativo com visão geral de finanças.  
- CRUD de transações com filtros avançados.  
- Gráficos interativos (Chart.js + ng2-charts).  
- Conversor de câmbio integrado a API externa.  
- Relatórios exportáveis em PDF e Excel.  
- Colaboração familiar com grupos e permissões.  
- Chatbot assistente para suporte e dicas financeiras.  

---

### 🌟 [Personal Finance API](https://github.com/rzend/personal-finance-api)
API backend em **Java Spring Boot** com **Arquitetura Hexagonal**, que fornece endpoints para o sistema de finanças pessoais e integra um **chatbot inteligente**.  
Principais destaques:
- Autenticação e segurança com JWT.  
- CRUD completo de transações e categorias.  
- Relatórios exportáveis em PDF e Excel (Apache POI + iTextPDF).  
- Conversão de câmbio via integração externa.  
- Gestão familiar com grupos e membros.  
- Microserviço de chatbot em Python (FastAPI + GPT4All).  
- Comunicação REST entre API Java e serviço Python.  
- Documentação clara com Swagger/OpenAPI.
